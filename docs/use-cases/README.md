# Use cases

One file per use case, named after it (for example `many-small-prs.md`). A few paragraphs are enough:

- what kind of work you hand to agents, and how much at once;
- where that work is tracked (locally, Jira, GitHub Issues, something else);
- what done means in your projects;
- any steps you want between your request and the result;
- what you use today, and where it falls short.
