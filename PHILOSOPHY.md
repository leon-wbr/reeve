# Philosophy

Coding agents are already good, and so is the terminal. reeve lives in the gaps between them and stays out of the way everywhere else.

Let the model think, and let code keep the facts. Do little, automate what repeats, and ask a person only what is theirs to decide.

## Principles

1. **Native first.** If an agent CLI, the terminal or a tool you already use does something, reeve uses it instead of rebuilding it. When a native feature catches up, ours is removed.
2. **Optional around the core.** Views, trackers, pipeline steps and the definition of done can each be swapped or left out. A TUI, Jira or GitHub Issues can be added; none is required.
3. **Local by default.** reeve's records stay on your machine. You choose what to share, and where.
4. **You define done.** What finishes an item is set per project, and a team can share a default.
5. **Automate, then prove it.** Anything you repeat can become automatic, and every feature has to beat the best setup it is measured against, or it goes.
