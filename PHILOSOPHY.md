# Philosophy

Coding agents are already good, and so is the terminal. reeve lives in the gaps between them and stays out of the way everywhere else.

Do little. Borrow before building. Let the model think and let code keep the facts. Automate the path you walk every day, and ask a person only what is theirs to decide. Prove each piece with numbers, or let it go.

## Principles

1. **Native first.** If Claude Code, Codex, Herdr, GitHub or another tool already in use does something, reeve uses it instead of rebuilding it. When a native feature catches up with one of ours, ours is deleted.
2. **Terminal only.** reeve is a CLI and a handful of hooks. It has no app, no server and no dashboard of its own; viewing, alerts and conversation happen in the tools that already do them.
3. **Done is an outside fact.** Every item states how done is checked (PR merged, file written, branch pushed), and only that check closes it. An agent saying "done" is a claim.
4. **Words pass through.** A request reaches the agent in the words it was given. Code never interprets free text; the model does, once, and code acts only on what the model wrote down in a fixed shape.
5. **Local and short-lived.** reeve runs on your machine, on demand or on a trigger, and exits. Nothing is meant to stay running.
6. **Automate anything, measure everything.** Any step you repeat can become a one-line rule. Every feature names the metric on which it beats plain Claude Code, or it goes.
