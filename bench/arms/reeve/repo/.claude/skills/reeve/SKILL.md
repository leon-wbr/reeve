reeve is installed on this machine. Use it for:

- heavy commands: test suites, e2e, builds and installs;
- long or parallel work, as named workers;
- handing off to a successor when a "Context check" says so.

Run `reeve --skill` before any of these; it prints the current manual with the exact commands.

Written by `reeve setup claude` for reeve 0.1.0.
