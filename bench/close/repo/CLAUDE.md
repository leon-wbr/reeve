# notes-kit

- Notes live in `notes/`, one Markdown file each.
- `origin` is the team's remote. Push a branch with `git push -u origin HEAD`.
- `node scripts/stamp.mjs NAME` prints a worker's stamp code.
- `node scripts/job.mjs CODE` is the long job: it takes about 4 minutes and writes `out/job.txt`.
- Do exactly what a task says about committing and pushing: some work must stay uncommitted or unpushed until the user has reviewed it.
