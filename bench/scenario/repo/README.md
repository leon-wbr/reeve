# stats-kit

## API

- `sum(xs)`: the sum of a list.
- `mean(xs)`: the arithmetic mean of a list.
- `loadConfig(overrides)`: the config, with defaults.
- `isVerbose(config)`: whether debug output is on.
- `formatNumber(n)`: a number formatted for display.
- `shuffle(xs)`: a shuffled copy of a list.
