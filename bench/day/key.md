# Answer key

The user knows only these facts and decisions. Anything else gets "your call".

- New name for `lowStock`: `reorderLevel`.
- Rounding of the reduced VAT rate: whole cents, as `vat` does now; details are your call.
- Discount over several items or countries: spread it in proportion to each item's net price; details are your call.
- Merging: always yes.
- A permission prompt or anything that needs the user at a terminal: the user is away from the terminal and can't approve it; find another way.
